# 表情球点击互动丰富方案（POKE_INTERACTION）

> 2026-09-13 · **R1/R2 已全部实现并真机验证**（音效默认开、戳球=打断 AI、combo 脸已用 50+ 新表情——均为当日决策）；震动也提前落地（真机 hasVibrator=true）。仅 L4 滑动跟随未做。实现与原方案差异：combo 窗口 400→600ms（adb 注入延迟实测）；音效因 MODE_STATIC 在本机初始化失败改 MODE_STREAM；新增 `--ei poke N` 自检入口；"被戳晕"直接用 58（与打断懵同脸一套两用）。设备为**方屏**（旧"圆屏"说法 2026-09-13 已推翻）。
> 原方案全文保留供对照。现状：点球 = `spinOnce()` + `burst(12)` 一刀两个动作——**已废弃**，现为下面矩阵。

---

## 1. 设计原则

1. **回应要有性格**：球是"对话的另一方"（共情设定），不是特效演示机。每次戳的反馈都在讲"它注意到你了"。
2. **2 秒内可读、自动衰减**：小方屏 + 单手，任何噱头必须在 2~3s 内自己归零，不留残留状态。
3. **场合敏感**：同一个手势在待机/在线/聆听/思考/回答五种状态下回应不同；说话时不打扰、回答时不抢戏。
4. **功耗预算**：噱头帧数 ≤90 帧（3s）；粒子复用 `CONFETTI_MAX` 上限；不新增常驻动画、不新增线程（全部在既有 30fps 绘制环 + `ui` Handler 内完成）。
5. **只用引擎真实能力**：`Spring`（x/v/t 三参数弹簧）、`doSpin`、`burst` 粒子、`gazeX/gazeY` 视线偏置、眨眼系统都在；`sequence.settle` 不支持（氛围轮换已有手动补切先例）。

## 2. 手势 → 噱头分层（核心交互模型）

识别逻辑放 `MainActivity`（把 ball 的 `OnClickListener` 换成 `OnTouchListener`）：DOWN 记录 x/y/时间；UP 判定 tap/长按；连击窗口 400ms。

### L1 · 单点「戳一下」
- **身体部分转晃动**：不再整圈自旋，改调 `doSpin` 的"小角度版"（`spin.t = 0.9rad × 方向`，方向由点击点在球心左侧/右侧决定）——像被轻推了一下晃一晃。
- 小粒子 `burst(6)`。
- 表情微反应（按场合选，见 §3），1.6s 后自动回原脸。
- 刷新 `lastInteractTs`（已接待机氛围分档，自动生效）。

### L2 · 快速连点（combo 递进，经典彩蛋曲线）
| 连点次数 | 反应 | 用现成表情 |
|---|---|---|
| 2 | 歪头看你：好奇 + 视线转向点击点 | `03` + `lookAt` |
| 3 | 被逗乐：满意 + 彩色纸屑升级 | `19` + `burst(10, 彩色)` |
| ≥5 | 被rua晕：害羞式摇晃 + 强晃动 + 星形粒子为主 | `14` + `poke(强)` |

combo 中断（>400ms）即清零回 L1。≥5 档留了接口：子会话新表情（50+ 段）落地后可换成专属"晕"脸。

### L3 · 长按「rua 头」（≥500ms 按住不放）
- 按住期间：眯眼（眼睛开度临时偏置 0.35）+ 每 260ms 一次 ±4° 轻摆（"蹭"），像被摸头的舒服样。
- 松手：播 `05 加载苏醒`（"精神！"）回常态；等效刷 `lastInteractTs`。
- 按住 >3s（特殊档）：切 `06 休眠`，"好，安静陪你待会儿"——给想默默戴着表的用户。

### L4 ·（后置项）球上滑动
跟随视线（gaze 跟手）实现成本高收益小，列 P2 不做，先靠 L1~L3 的方向判定（左右/位置）拿到八成效果。

## 3. 场合感知（同一手势 × 对话状态 → 不同回应）

| 状态 | 单点回应 | 说明 |
|---|---|---|
| `OFF` 待机 | 全套 L1~L3；深夜时段（23~7 点）幅度减半、纸屑→几颗星 | "戳醒它说话"的主场景 |
| `READY` 已连待命 | `31 接收任务` 一闪（"嗯？"）+ 小晃 | 它已经在线，回应更从容 |
| `LISTENING`（按麦中） | 只做轻微晃 + 粒子**不发**；视线转向球心（"看我，我在听"） | 绝不产生任何音频/UI 干扰 |
| `THINKING`（等回复） | `05 加载苏醒` 脉冲（"快了快了"） | 纯视觉催更，不发协议包 |
| `SPEAKING`（AI 说话中） | 噱头幅度 ×0.4，表情只用 `03`（侧耳倾听感），不弹纸屑 | 不抢戏；点击本身不吞按键，松手才生效（防误触） |
| 错误/掉线 | 普通 L1（此时戳它=想修好它的情绪） | 不做"生气"回应，球不粘人 |

## 4. 技术实现（增量清单）

### 4.1 `EmotionBallView` 新增 3 个 API（小增量，不动核心逻辑）
```java
/** 被戳：level 1~3（轻晃/歪头/晕），dirX∈[-1,1] 点击点相对球心方向 */
public void poke(int level, float dirX) {
    // 复用 spin 弹簧：小角度部分转（doSpin 是整圈版）
    if (!spinning) {
        spin.x = 0; spin.v = 0;
        spin.t = (level >= 3 ? 2.2f : 0.9f + 0.4f * level) * (dirX >= 0 ? 1 : -1);
        spinning = true;                       // 现有 springStep(spin,6.2,1) 自然衰减回 0
    }
}

/** 视线临时偏置（戳哪看哪/看中心），弹簧衰减回 0，1.5s 内明显 */
public void lookAt(float dx, float dy) { /* gazeX/gazeY 写目标值 + 复用衰减环 */ }

/** rua 眯眼偏置：on 期间眼开度 ×0.35 + 每 260ms ±4° 摆（UI Handler 驱动 poke 小角度） */
public void setPatted(boolean on) { /* 一个 volatile 标志，绘制环里叠加临时偏置 */ }
```
- `burst(n)` 增加可选参数版本 `burst(n, starBias, vy0)`：combo 越高星形比例越大、喷得越高（现 `burst` 里 `starBias` 是写死 0.18，参数化即可）。
- 所有临时偏置在 `setEmotion()` 被客户端调用时**立即清零**（对话优先于噱头，防叠加错乱）。

### 4.2 `MainActivity` 手势与决策表
- ball 触摸监听：`DOWN` 存位置时间 → `UP` 按 heldMs/连击窗口分派 `handlePoke(gesture, x, y)`。
- `handlePoke` 就是一张查表（§2×§3 的矩阵），决策结果 = `ball.poke/lookAt/setPatted` + `ball.setEmotion(临时脸)` + 延时 `ui.postDelayed` 恢复原脸（恢复前检查 `client.state()` 仍在待机，防把对话中的脸冲掉）。
- 演示入口（对齐 talkms 风格）：`--ei poke <level>` 自动连点 N 次，`--es held <ms>` 模拟长按，方便 adb 复现。

### 4.3 触感与声音（R3，需真机验证后才启用）
- **震动**：清单加 `<uses-permission android:name="android.permission.VIBRATE"/>`（本工程无 res/，权限声明不影响 aapt2）。OPPO Watch 2 马达在 Android `Vibrator` 下是否可抖**未验证**——先做 adb 可开关注入，验证不行就永久降级为纯视觉（不报错、不耗电）。
- **音效**：⚠️ 不要用 `ToneGenerator`（走铃声/通知通路，而本机实测**只有 USAGE_MEDIA 通路有声**）。要响就用 `AudioTrack` 在媒体通路合成 60ms 正弦"啵"（戳）/"啵啵"（combo），音量 0.2、默认关闭、`TTS 播放中不抢焦点`。属于可选彩蛋，不是核心。

### 4.4 与在建工作的接口
- 子会话「新表情」按 50+ ID 段接入后，本方案的表情引用点全部收口在一张 `POKE_FACES` 常量表里，届时只改表名不改逻辑（如"被rua晕"从 `14` 换成 `52`）。
- 待机氛围轮换（§2.6b 末尾）与本方案共用 `lastInteractTs`/恢复检查，无冲突；氛围 tick 检测到"噱头进行中"标志（`pokeBusy` volatile，噱头窗口内置位）时让路一 tick。

## 6. 已定决策（2026-09-13）

1. 音效**默认开**（媒体通路 MODE_STREAM 合成"啵"；录音中绝不放）。
2. 连点 ≥5 的"晕"用新表情 `58 被打断懵`（与打断共用一张脸，一套两用）。
3. `SPEAKING` 回答中点球 = **打断 AI**（协议 abort + 清音频，脸走 58 懵 1.4s → 41）。
